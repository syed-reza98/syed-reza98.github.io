# Syed Salman Reza - Portfolio Website

Personal portfolio website built with Next.js, TypeScript, and Tailwind CSS, showcasing my projects and skills as a full-stack developer.

## 🚀 Live Demo

Visit the live site: [syed-reza98.github.io](https://syed-reza98.github.io)

## ⚡ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org) with App Router
- **Language**: TypeScript
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com)
- **Icons**: [Radix Icons](https://www.radix-ui.com/icons)
- **UI Components**: Custom components with [Radix UI Primitives](https://www.radix-ui.com/primitives)
- **Deployment**: GitHub Pages (automated via GitHub Actions)

## 📋 Features

- ✅ Modern, responsive design
- ✅ Dark/Light theme toggle with persistence
- ✅ Fully accessible (WCAG 2.1 AA compliant)
- ✅ SEO optimized
- ✅ Fast page loads with static generation
- ✅ Mobile-first approach
- ✅ Smooth animations and transitions

## 🛠️ Development

### Prerequisites

- Node.js 20.x or higher
- npm or yarn

### Getting Started

1. Clone the repository:
```bash
git clone https://github.com/syed-reza98/syed-reza98.github.io.git
cd syed-reza98.github.io
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Available Scripts

- `npm run dev` - Start development server with Turbopack
- `npm run build` - Build for production (static export)
- `npm run start` - Start production server
- `npm run lint` - Run ESLint

## 📁 Project Structure

```
├── app/                    # Next.js App Router pages
│   ├── layout.tsx         # Root layout with header/footer
│   ├── page.tsx           # Home page
│   └── globals.css        # Global styles
├── components/            # Reusable components
│   ├── layout/           # Layout components (Header, Footer)
│   └── ui/               # UI components (Button, etc.)
├── lib/                   # Utility functions
├── public/               # Static assets
└── .github/workflows/    # GitHub Actions workflows
```

## 🎨 Design System

- **Colors**: CSS custom properties with light/dark theme support
- **Typography**: Geist Sans and Geist Mono fonts
- **Spacing**: Consistent spacing scale based on Tailwind defaults
- **Components**: Built with accessibility in mind using Radix UI primitives
