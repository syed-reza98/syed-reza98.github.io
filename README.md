# Syed Salman Reza - Portfolio Website

Personal portfolio website — "The Engineer's Ledger" — a single-page static site showcasing my projects and experience as a full-stack software engineer.

## 🚀 Live Demo

Visit the live site: [syed-reza98.github.io](https://syed-reza98.github.io)

## ⚡ Tech Stack

- Plain HTML, CSS, and vanilla JavaScript — no build step
- **Deployment**: GitHub Pages (automated via GitHub Actions)

## 📋 Features

- ✅ Modern, responsive design
- ✅ Dark/Light theme support (follows system preference)
- ✅ Accessible (skip link, focus states, reduced-motion support)
- ✅ SEO optimized
- ✅ Fast page loads — static HTML, no framework overhead

## 🛠️ Development

Open `index.html` directly in a browser, or serve it locally:

```bash
npx serve .
```

## 📁 Project Structure

```
├── index.html             # The entire site
├── favicon.ico
├── .nojekyll
└── .github/workflows/      # GitHub Actions deployment workflow
```
